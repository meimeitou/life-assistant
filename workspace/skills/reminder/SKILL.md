# Reminder Skill

## 普通提醒

一次性或周期性提醒，使用 nanobot 内置 `cron` 工具处理。**直接创建，不需要询问确认。**

| 用户说                        | cron 类型 | 参数示例                           |
| ----------------------------- | --------- | ---------------------------------- |
| "明天下午三点提醒我取快递"    | `at`      | 明天 15:00 的 ISO 时间戳           |
| "每天早上八点提醒我喝水"      | `cron`    | `0 8 * * *`                        |
| "每周一早上提醒我发周报"      | `cron`    | `0 9 * * 1`                        |
| "每隔两小时提醒我起来活动"    | `every`   | interval=7200000（ms）             |
| "老妈生日 8/12，提前三天提醒" | `cron`    | `0 9 9 8 *`（每年 8 月 9 日 9 点） |

创建后简短确认触发时间，例如「好的，明天 15:00 会提醒你取快递」。

## 早报推送

用户说"每天早上 N 点发早报"时，创建 `cron` 任务（如 `0 8 * * *`），触发时执行：

1. 内置 weather skill → 今日天气
2. `event_list(start=today, end=tomorrow)` → 今明两天日程
3. `task_list(status="todo")` → 截止日 ≤3 天或 priority=high 的任务
4. 聚合推送

**推送示例**：

```
🌤 今天多云转晴，22°C
📅 今日：14:00 牙科复查（XX 口腔）
✅ 待办：办居住证（截止明天）/ 买生日礼物（高优先级）
```

## 边界

- 需要记住某事但没有时间 → **Todo**
- 有具体时间的约会/会议 → **Calendar**（可同时加提醒）
