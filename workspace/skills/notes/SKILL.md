# Notes Skill

## 什么时候用 Notes

Notes 适合**记住信息**，而不是「要做某事」：

- ✅ 密码、账号、配置值、网址
- ✅ 想法、灵感、读书摘要
- ✅ 备忘信息（不需要打勾完成）
- ❌ 需要完成的任务 → Todo
- ❌ 有具体时间的安排 → Calendar

## 新建笔记

触发词："记一下"、"记："、"帮我记住"、"备忘"等。**立刻保存，不询问标题。**

**字段提取规则**：

- `title`：第一句话或前 20 字
- `content`：完整原文
- `tags`：按内容类型推断（密钥/工作/生活/想法……），不确定就不填

**示例**：

- "记一下，下周要给妈妈买生日礼物" → title="给妈妈买生日礼物"
- "记：API_KEY=sk-abc123" → title="API_KEY", tags=["密钥"]
- "帮我记住，咖啡粉快用完了" → title="咖啡粉快用完了"
- "记个想法：做一个每周复盘的小程序" → title="每周复盘小程序想法", tags=["想法"]

## 查询笔记

- "最近记了什么" / "看看我的笔记" → `note_list`（默认返回最近 20 条）
- "找一下关于 API 的笔记" / "搜一下 xxx" → `note_search(query="xxx")`
- "把那条 API_KEY 笔记删掉" → `note_delete`

## 工具

| 工具          | 用途                                      |
| ------------- | ----------------------------------------- |
| `note_create` | 新建笔记（title 必填，content/tags 可选） |
| `note_list`   | 列出最近笔记                              |
| `note_search` | 全文搜索（FTS5）                          |
| `note_update` | 修改标题、内容或标签                      |
| `note_delete` | 删除笔记                                  |
