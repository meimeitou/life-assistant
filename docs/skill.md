# 功能规格

> 个人单用户场景，聚焦"别忘事、少费脑、快查信息"三个核心价值。
> 所有功能通过自然语言交互，无需学习命令。

---

## 范围说明

| 在范围内                       | 不在范围内            |
| ------------------------------ | --------------------- |
| 提醒 / 日程 / 待办 / 笔记      | 多用户协作 / 家庭共享 |
| 天气查询 / 信息快查 / 翻译     | 智能家居控制          |
| 定时自动推送（早报、账单提醒） | 记账 / 预算管理       |
| 跨渠道（微信 + Telegram）统一  | 购物比价 / 库存管理   |

---

## 1. 提醒（Reminder）

**核心场景**：不让重要的事情被遗忘。

| 功能       | 示例交互                              | 实现方式             |
| ---------- | ------------------------------------- | -------------------- |
| 一次性提醒 | "明天下午三点提醒我取快递"            | nanobot cron `at`    |
| 周期性提醒 | "每月 25 号提醒我还信用卡"            | nanobot cron `every` |
| 重要日期   | "老妈生日 8 月 12 号，提前三天提醒我" | event + cron         |

**触发方式**：到时间后由 nanobot 主动推送到微信 / Telegram。

---

## 2. 日历事件（Calendar）

**核心场景**：管理有明确时间的事项。

| 功能        | 示例交互                                    |
| ----------- | ------------------------------------------- |
| 创建事件    | "下周三下午两点有个牙科复查，地点：XX 口腔" |
| 查询日程    | "我这周有什么安排" / "下个月有哪些事"       |
| 修改 / 删除 | "把周三的复查改到周四下午"                  |

**存储**：SQLite `events` 表，通过 `life-mcp` 工具读写。

---

## 3. 待办事项（Todo）

**核心场景**：管理需要跟进但无固定时间的任务。

| 功能        | 示例交互                                      |
| ----------- | --------------------------------------------- |
| 新增任务    | "记一下，要去办居住证" / "把'修电脑'加到待办" |
| 查询任务    | "我现在有哪些待办" / "高优先级的任务有哪些"   |
| 完成 / 更新 | "居住证办好了" / "把买书包改成高优先级"       |
| 临期提醒    | 截止日前一天自动提醒（通过 cron 轮询）        |

**字段**：标题、描述、状态（todo / in_progress / done）、优先级、截止日、标签。

**存储**：SQLite `tasks` 表，通过 `life-mcp` 工具读写。

---

## 4. 快速笔记（Note）

**核心场景**：随手记录，事后能找回。

| 功能 | 示例交互                                                |
| ---- | ------------------------------------------------------- |
| 记录 | "记一下：推荐餐厅：XX 火锅，地址：XX 路"                |
| 搜索 | "之前记的那家火锅叫什么" / "找找我记过的关于搬家的内容" |
| 整理 | "帮我列出所有打了'旅行'标签的笔记"                      |

**搜索**：SQLite FTS5 全文检索，支持模糊匹配。

**存储**：SQLite `notes` 表，通过 `life-mcp` 工具读写。

---

## 5. 天气（Weather）

**核心场景**：出门前快速决策。

| 功能     | 示例交互                                 |
| -------- | ---------------------------------------- |
| 当前天气 | "今天天气怎么样"                         |
| 穿衣建议 | "今天出门穿什么合适"                     |
| 未来天气 | "这周末会下雨吗"                         |
| 主动推送 | 每天早上播报天气（通过 cron + 天气 API） |

**实现**：nanobot 内置 weather skill（wttr.in），无需自定义 Skill。

---

## 6. 信息查询（Search）

**核心场景**：不切换 App，直接问。

| 功能     | 示例交互                                      |
| -------- | --------------------------------------------- |
| 网页搜索 | "附近哪里可以办身份证" / "社保断交有什么影响" |
| 快速计算 | "今天到月底还有几天" / "500 美元是多少人民币" |
| 流程查询 | "护照续签需要什么材料" / "公积金怎么提取"     |

**实现**：nanobot 内置 `web_search` + `web_fetch`，无需额外 Skill。

---

## 7. 翻译（Translate）

**核心场景**：处理外文内容。

| 功能     | 示例交互                     |
| -------- | ---------------------------- |
| 文字翻译 | "翻译一下这段英文：..."      |
| 语境翻译 | "这句话怎么用中文自然地表达" |

**实现**：LLM 原生能力，直接回答，无需 Skill 或外部 API。

---

## 8. 早报推送（Morning Briefing）

**核心场景**：早上一条消息掌握今日概况。

**内容**：

1. 今日天气 + 穿衣建议
2. 今日日历事件
3. 截止日在 3 天内的待办
4. 高优先级未完成任务

**实现**：nanobot cron 每天早上定时触发，聚合以上数据后推送到微信。

## 9. 账本（Ledger）

**核心场景**：随手记收支，月底查一下花哪去了。

| 功能     | 示例交互                                        |
| -------- | ----------------------------------------------- |
| 记支出   | "花了 38 块吃饭" / "打车花了 23.5"              |
| 记收入   | "收到工资 15000"                                |
| 查流水   | "看看最近的账单" / "这个月餐饮花了多少"         |
| 汇总统计 | "这个月总共花了多少" / "帮我看看今年的收支情况" |

**字段**：金额、类型（收入/支出）、分类（餐饮/交通/购物/医疗/娱乐/工资/其他）、备注、日期。

**存储**：SQLite `transactions` 表，通过 `life-mcp` 工具读写。
